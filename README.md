# Portfolio Website

A responsive personal portfolio website built with **React**, **Vite**, **Tailwind CSS**, and **GSAP**.

## Overview

This project showcases a modern portfolio layout with:
- Home, About, Skills, Projects, Services, Achievements, Contact, and Footer sections
- Dark/light theme toggle
- Smooth scrolling and responsive design
- Custom icon components and social links

## Built With

- React 19
- Vite 7
- Tailwind CSS 4
- GSAP
- Lucide React

## Getting Started

### Prerequisites

- Node.js 18+ or newer
- npm

### Install

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

Open the local URL shown in the terminal to view the portfolio.

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

- `src/App.jsx` — main app component and theme handling
- `src/main.jsx` — React entry point
- `src/components/` — portfolio sections and reusable UI components
- `src/index.css` — global styles

## Notes

- The page title is currently set in `index.html`.
- Update the content and personal links in `src/components/*` to customize the portfolio.
